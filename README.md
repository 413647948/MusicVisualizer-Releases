# MusicVisualizer（公开下载）

Android 音乐可视化工具。将系统混音或本地音乐实时渲染为 **节奏 / 旋律 / 流动 / 特效** 四频段可视化，适配手机与平板。

> 本仓库 **仅用于公开下载**；源代码闭源，不在公开仓库中提供。

## 最新版本

- **v1.3** — `MusicVisualizer-v1.3.apk`（Android 8.0 / API 26 及以上）
- 直接下载 APK 安装即可，无需 Google Play。
